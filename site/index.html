More space, less clutter.

Command-line tool for Windows 10 and 11. Clears caches, uninstalls apps with their leftovers, shows what takes up space. Every deleting command has a preview.

Install Source on GitHub

Windows 10 / 11 · Windows PowerShell 5.1 · GPL-3.0

Features

All commands run through sw; without an argument it opens a menu.

Deep Clean

Remove temp files, caches, logs and browser leftovers.

sw clean

Uninstall

Remove apps with their own uninstaller; verified leftovers go to the Recycle Bin.

sw uninstall

Optimize

Flush DNS, optimize the system drive, check disk health.

sw optimize

Disk analysis

Shows in the terminal which folders and files take up space.

sw analyze

Live monitoring

CPU, RAM, disks, network and processes in real time.

sw status

Project purge

Remove old build artifacts such as node_modules or bin/obj.

sw purge

Debloat Windows

Remove preinstalled apps and optional features from a reviewed list; --restore brings them back.

sw features

Check a PC once

Read-only, no installation; the result is an HTML report.

sw check

History

Shows what was removed and when, also as JSON.

sw history

Look first, then delete

--dry-run shows what would be removed and changes nothing. For sw features it lists the exact Windows commands.

--debug also writes a detailed log.

PS> sw clean --dry-run
PS> sw uninstall --dry-run
PS> sw optimize --dry-run
PS> sw purge --dry-run
PS> sw features --dry-run
PS> sw history

Safety

What cannot be shown to be safe to remove stays where it is.

  • Protected folders: C:\Windows, C:\Program Files, Windows Defender and the profile root are never touched, nor are keys and credentials.
  • Whitelist: protect your own paths with sw clean --whitelist.
  • Recycle Bin: uninstall leftovers and files deleted in sw analyze go to the Recycle Bin.
  • Log: every change is recorded in operations.log, readable with sw history.
  • Normal rights: runs as a normal user; system steps only in an administrator PowerShell, Sweepr never requests rights itself.
  • Confirmation: uninstall, purge and remove ask before removing.

Installation

Portable

Install nothing: unzip the portable ZIP from the releases, for example to a USB stick, and run sw.exe. All data stays in the folder.

Install ZIP

Unzip the release ZIP and run the installer. Needs neither Git nor Go.

powershell -ExecutionPolicy Bypass -File .\install.ps1 -AddToPath

Quick install

Installs from source and updates with sw update. Needs Git.

iwr -useb https://raw.githubusercontent.com/brummilab/Sweepr/main/quick-install.ps1 | iex

Releases are not code-signed; every release includes SHA256SUMS.txt to check the downloads. Remove with sw remove.
