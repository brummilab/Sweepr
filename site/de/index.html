Sweepr
Funktionen Sicherheit Installation Roadmap English GitHub

Mehr Platz, weniger Ballast.

Kommandozeilen-Tool für Windows 10 und 11. Leert Caches, deinstalliert Apps samt Resten, zeigt, was Platz belegt. Jeder löschende Befehl hat eine Vorschau.

Installieren Quellcode auf GitHub

Windows 10 / 11 · Windows PowerShell 5.1 · GPL-3.0

Funktionen

Alle Befehle laufen über sw; ohne Argument öffnet sich ein Menü.

Deep Clean

Temp-Dateien, Caches, Logs und Browser-Reste entfernen.

sw clean

Deinstallieren

Apps mit ihrem eigenen Uninstaller entfernen, geprüfte Reste in den Papierkorb.

sw uninstall

Optimieren

DNS leeren, Systemlaufwerk optimieren, Datenträgerzustand prüfen.

sw optimize

Speicheranalyse

Zeigt im Terminal, welche Ordner und Dateien Platz belegen.

sw analyze

Live-Monitoring

CPU, RAM, Datenträger, Netzwerk und Prozesse in Echtzeit.

sw status

Projekt-Purge

Alte Build-Artefakte wie node_modules oder bin/obj entfernen.

sw purge

Windows entschlacken

Vorinstallierte Apps und optionale Features aus einer geprüften Liste entfernen; --restore holt sie zurück.

sw features

PC einmal prüfen

Nur lesend, ohne Installation; Ergebnis als HTML-Bericht.

sw check

Verlauf

Zeigt, was wann entfernt wurde, auch als JSON.

sw history

Erst ansehen, dann löschen

--dry-run zeigt, was entfernt würde, und ändert nichts. Bei sw features stehen dort die exakten Windows-Befehle.

--debug schreibt zusätzlich ein Detail-Log.

PS> sw clean --dry-run
PS> sw uninstall --dry-run
PS> sw optimize --dry-run
PS> sw purge --dry-run
PS> sw features --dry-run
PS> sw history

Sicherheit

Was nicht nachweislich sicher entfernt werden kann, bleibt liegen.

  • Geschützte Ordner: C:\Windows, C:\Program Files, Windows Defender und das Profil-Stammverzeichnis werden nie angefasst, ebenso Schlüssel- und Anmeldedaten.
  • Whitelist: eigene Pfade schützen mit sw clean --whitelist.
  • Papierkorb: Deinstallationsreste und in sw analyze gelöschte Dateien gehen in den Papierkorb.
  • Protokoll: jede Änderung steht in operations.log, lesbar mit sw history.
  • Normale Rechte: läuft als normaler Benutzer; System-Schritte nur in einer Administrator-PowerShell, Sweepr fordert nie selbst Rechte an.
  • Nachfragen: uninstall, purge und remove fragen vor dem Entfernen.

Installation

Portable

Nichts installieren: das portable ZIP aus den Releases entpacken, z. B. auf einen USB-Stick, und sw.exe starten. Alle Daten bleiben im Ordner.

Install-ZIP

Release-ZIP entpacken und den Installer starten. Braucht weder Git noch Go.

powershell -ExecutionPolicy Bypass -File .\install.ps1 -AddToPath

Quick-Install

Installiert aus dem Quellcode und lässt sich mit sw update aktualisieren. Braucht Git.

iwr -useb https://raw.githubusercontent.com/brummilab/Sweepr/main/quick-install.ps1 | iex

Releases sind nicht code-signiert; jedes Release enthält SHA256SUMS.txt zum Prüfen der Downloads. Entfernen mit sw remove.
